# Containers — довідник DVA-C02

Ключові поняття, сценарії та типові екзаменаційні пастки для сервісів
цієї категорії.

## Amazon ECR

**Призначення:** Керований registry для зберігання OCI/Docker container
images.

### Ключові терміни

| Термін                   | Визначення                                                                                                            |
|--------------------------|-----------------------------------------------------------------------------------------------------------------------|
| **Registry**             | У контексті Amazon ECR це поняття описує відповідний елемент сервісу, його налаштування або поведінку під час роботи. |
| **Repository**           | Логічне сховище пакетів або container images.                                                                         |
| **Image**                | У контексті Amazon ECR це поняття описує відповідний елемент сервісу, його налаштування або поведінку під час роботи. |
| **Tag**                  | У контексті Amazon ECR це поняття описує відповідний елемент сервісу, його налаштування або поведінку під час роботи. |
| **Digest**               | У контексті Amazon ECR це поняття описує відповідний елемент сервісу, його налаштування або поведінку під час роботи. |
| **Layer**                | Пакет спільних бібліотек або файлів, які підключаються до Lambda function.                                            |
| **Lifecycle Policy**     | Правила автоматичного видалення старих або непотрібних образів.                                                       |
| **Image Scanning**       | У контексті Amazon ECR це поняття описує відповідний елемент сервісу, його налаштування або поведінку під час роботи. |
| **Enhanced Scanning**    | У контексті Amazon ECR це поняття описує відповідний елемент сервісу, його налаштування або поведінку під час роботи. |
| **Repository Policy**    | У контексті Amazon ECR це поняття описує відповідний елемент сервісу, його налаштування або поведінку під час роботи. |
| **Authentication Token** | У контексті Amazon ECR це поняття описує відповідний елемент сервісу, його налаштування або поведінку під час роботи. |
| **Cross-account Access** | У контексті Amazon ECR це поняття описує відповідний елемент сервісу, його налаштування або поведінку під час роботи. |
| **Replication**          | У контексті Amazon ECR це поняття описує відповідний елемент сервісу, його налаштування або поведінку під час роботи. |

**Типовий екзаменаційний сценарій:** ECS/EKS має завантажити приватний
контейнерний образ → ECR плюс IAM/repository policy.

**Екзаменаційна пастка:** ECR зберігає образи, але не запускає
контейнери.

## Amazon ECS

**Призначення:** AWS-native оркестратор контейнерів на EC2 або Fargate.

### Ключові терміни

| Термін                   | Визначення                                                                                                            |
|--------------------------|-----------------------------------------------------------------------------------------------------------------------|
| **Cluster**              | У контексті Amazon ECS це поняття описує відповідний елемент сервісу, його налаштування або поведінку під час роботи. |
| **Task Definition**      | Опис контейнерів, ресурсів, ролей, мережі та налаштувань ECS task.                                                    |
| **Task**                 | Стан Step Functions, який виконує роботу через сервісну інтеграцію або код.                                           |
| **Service**              | Стабільна мережева абстракція для доступу до Kubernetes Pods.                                                         |
| **Container Definition** | У контексті Amazon ECS це поняття описує відповідний елемент сервісу, його налаштування або поведінку під час роботи. |
| **EC2 Launch Type**      | У контексті Amazon ECS це поняття описує відповідний елемент сервісу, його налаштування або поведінку під час роботи. |
| **Fargate**              | У контексті Amazon ECS це поняття описує відповідний елемент сервісу, його налаштування або поведінку під час роботи. |
| **Capacity Provider**    | У контексті Amazon ECS це поняття описує відповідний елемент сервісу, його налаштування або поведінку під час роботи. |
| **Desired Count**        | У контексті Amazon ECS це поняття описує відповідний елемент сервісу, його налаштування або поведінку під час роботи. |
| **Deployment**           | Kubernetes controller для декларативного rollout і підтримки ReplicaSets.                                             |
| **Task Role**            | IAM Role для коду, який виконується всередині ECS task.                                                               |
| **Task Execution Role**  | IAM Role для ECS/Fargate agent: pull image, logs, startup secrets.                                                    |
| **awsvpc**               | У контексті Amazon ECS це поняття описує відповідний елемент сервісу, його налаштування або поведінку під час роботи. |
| **Service Discovery**    | У контексті Amazon ECS це поняття описує відповідний елемент сервісу, його налаштування або поведінку під час роботи. |
| **Health Check**         | Перевірка доступності та працездатності target.                                                                       |
| **Service Auto Scaling** | У контексті Amazon ECS це поняття описує відповідний елемент сервісу, його налаштування або поведінку під час роботи. |
| **ECS Exec**             | У контексті Amazon ECS це поняття описує відповідний елемент сервісу, його налаштування або поведінку під час роботи. |

**Типовий екзаменаційний сценарій:** Потрібно запускати контейнери без
Kubernetes control plane → ECS.

**Екзаменаційна пастка:** Task Role належить застосунку в контейнері;
Task Execution Role потрібна агенту ECS для pull image, logs та startup
secrets.

Kubernetes workloads.

| **Worker Node**        | У контексті Amazon EKS це поняття описує відповідний елемент сервісу, його налаштування або поведінку під час роботи. |

| **IAM Auth**           | У контексті Amazon EKS це поняття описує відповідний елемент сервісу, його налаштування або поведінку під час роботи. |
