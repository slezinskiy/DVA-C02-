# Amazon EventBridge

**Категорія:** Application Integration

**Призначення:** Serverless event bus для маршрутизації подій за
правилами та інтеграції сервісів.

## Словник термінів

| Термін                         | Визначення                                                                                                                    |
|--------------------------------|-------------------------------------------------------------------------------------------------------------------------------|
| **Event**                      | Повідомлення про факт або зміну, що сталася.                                                                                  |
| **Event Bus**                  | Канал, який приймає події та маршрутизує їх до targets.                                                                       |
| **Default/Custom/Partner Bus** | У контексті Amazon EventBridge це поняття описує відповідний елемент сервісу, його налаштування або поведінку під час роботи. |
| **Rule**                       | Умова зіставлення події та конфігурація її подальшої доставки.                                                                |
| **Event Pattern**              | Опис структури/значень полів події, які мають збігтися з правилом.                                                            |
| **Target**                     | Сервіс або ресурс, якому передається подія.                                                                                   |
| **Input Transformer**          | Правило перетворення payload перед передаванням target.                                                                       |
| **Archive**                    | Збереження подій EventBridge для подальшого replay.                                                                           |
| **Replay**                     | Повторне відтворення раніше збережених подій.                                                                                 |
| **Scheduler**                  | Керований запуск дії одноразово або за розкладом.                                                                             |
| **Retry**                      | Правило повторного запуску стану після помилки.                                                                               |
| **DLQ**                        | У контексті Amazon EventBridge це поняття описує відповідний елемент сервісу, його налаштування або поведінку під час роботи. |
| **Schema Registry**            | У контексті Amazon EventBridge це поняття описує відповідний елемент сервісу, його налаштування або поведінку під час роботи. |

## Типовий екзаменаційний сценарій

Потрібно маршрутизувати події за вмістом до різних targets →
EventBridge.

## Екзаменаційна пастка

Не тотожний SQS: EventBridge маршрутизує події, SQS буферизує
повідомлення.

## Що повторити

- Призначення сервісу та типові сценарії використання.
- Основні API, інтеграції та необхідні IAM permissions.
- Обробку помилок, retries, throttling і logging, якщо вони застосовні.
- Обмеження та взаємодію з іншими AWS-сервісами.
