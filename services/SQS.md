# Amazon SQS

**Категорія:** Application Integration

**Призначення:** Керована черга повідомлень для асинхронного decoupling
producer і consumer.

## Словник термінів

| Термін                 | Визначення                                                                                                            |
|------------------------|-----------------------------------------------------------------------------------------------------------------------|
| **Standard Queue**     | У контексті Amazon SQS це поняття описує відповідний елемент сервісу, його налаштування або поведінку під час роботи. |
| **FIFO Queue**         | У контексті Amazon SQS це поняття описує відповідний елемент сервісу, його налаштування або поведінку під час роботи. |
| **Visibility Timeout** | Період, коли отримане SQS повідомлення приховане від інших consumer.                                                  |
| **Long Polling**       | Очікування повідомлення до заданого часу, що зменшує порожні receive calls.                                           |
| **Short Polling**      | Негайне опитування черги без тривалого очікування.                                                                    |
| **Message Retention**  | Максимальний час зберігання повідомлення в черзі.                                                                     |
| **DLQ**                | У контексті Amazon SQS це поняття описує відповідний елемент сервісу, його налаштування або поведінку під час роботи. |
| **Redrive Policy**     | Правило, яке визначає умови переміщення повідомлення до DLQ.                                                          |
| **maxReceiveCount**    | Максимальна кількість отримань повідомлення до переміщення в DLQ.                                                     |
| **Message Group ID**   | Ідентифікатор групи FIFO, у межах якої зберігається порядок.                                                          |
| **Deduplication ID**   | Ідентифікатор, який допомагає виявляти дублікати FIFO-повідомлень.                                                    |
| **Delay Queue**        | У контексті Amazon SQS це поняття описує відповідний елемент сервісу, його налаштування або поведінку під час роботи. |
| **At-least-once**      | Модель доставки, за якої повідомлення може бути доставлене повторно.                                                  |

## Типовий екзаменаційний сценарій

Потрібно буферизувати роботу, згладжувати піки та відокремити producer
від consumer → SQS.

## Екзаменаційна пастка

Отримання не видаляє повідомлення. Після успішної обробки потрібен
DeleteMessage. Доставка може бути повторною — потрібна idempotency.

## Що повторити

- Призначення сервісу та типові сценарії використання.
- Основні API, інтеграції та необхідні IAM permissions.
- Обробку помилок, retries, throttling і logging, якщо вони застосовні.
- Обмеження та взаємодію з іншими AWS-сервісами.
