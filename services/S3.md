# Amazon S3

**Категорія:** Storage

**Призначення:** Об’єктне сховище для файлів, backup, data lakes, static
content та інтеграцій.

## Типовий екзаменаційний сценарій

Потрібне масштабоване object storage або статичний контент → S3.

## Екзаменаційна пастка

S3 має strong read-after-write consistency для PUT/DELETE. ETag не
завжди дорівнює MD5; приватний CloudFront origin захищайте OAC.

## Що повторити

- Призначення сервісу та типові сценарії використання.
- Основні API, інтеграції та необхідні IAM permissions.
- Обробку помилок, retries, throttling і logging, якщо вони застосовні.
- Обмеження та взаємодію з іншими AWS-сервісами.
