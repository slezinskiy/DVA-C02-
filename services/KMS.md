# AWS KMS

**Категорія:** Security, Identity, and Compliance

**Призначення:** Керування криптографічними ключами для шифрування,
дешифрування та підпису.

## Словник термінів

| Термін                    | Визначення                                                                                                         |
|---------------------------|--------------------------------------------------------------------------------------------------------------------|
| **KMS Key**               | У контексті AWS KMS це поняття описує відповідний елемент сервісу, його налаштування або поведінку під час роботи. |
| **Key Material**          | У контексті AWS KMS це поняття описує відповідний елемент сервісу, його налаштування або поведінку під час роботи. |
| **AWS Owned/Managed Key** | У контексті AWS KMS це поняття описує відповідний елемент сервісу, його налаштування або поведінку під час роботи. |
| **Customer Managed Key**  | У контексті AWS KMS це поняття описує відповідний елемент сервісу, його налаштування або поведінку під час роботи. |
| **Key Policy**            | Основна resource policy, що визначає доступ до KMS key.                                                            |
| **Grant**                 | У контексті AWS KMS це поняття описує відповідний елемент сервісу, його налаштування або поведінку під час роботи. |
| **Envelope Encryption**   | Схема, у якій дані шифруються data key, а сам data key шифрується KMS key.                                         |
| **Data Key**              | Ключ, який шифрує фактичні дані; може бути захищений KMS key.                                                      |
| **GenerateDataKey**       | У контексті AWS KMS це поняття описує відповідний елемент сервісу, його налаштування або поведінку під час роботи. |
| **Encrypt/Decrypt**       | У контексті AWS KMS це поняття описує відповідний елемент сервісу, його налаштування або поведінку під час роботи. |
| **Rotation**              | Заміна секретного значення або key material за розкладом/процедурою.                                               |
| **Alias**                 | Іменований покажчик на конкретну версію Lambda.                                                                    |
| **ARN**                   | У контексті AWS KMS це поняття описує відповідний елемент сервісу, його налаштування або поведінку під час роботи. |
| **Multi-Region Key**      | У контексті AWS KMS це поняття описує відповідний елемент сервісу, його налаштування або поведінку під час роботи. |
| **Encryption Context**    | Не секретні authenticated metadata, які мають збігатися під час decrypt.                                           |

## Типовий екзаменаційний сценарій

Потрібне кероване шифрування даних із контролем ключів → KMS.

## Екзаменаційна пастка

Перевіряйте Key Policy разом з IAM policy; KMS key policy є ключовою
частиною authorization.

## Що повторити

- Призначення сервісу та типові сценарії використання.
- Основні API, інтеграції та необхідні IAM permissions.
- Обробку помилок, retries, throttling і logging, якщо вони застосовні.
- Обмеження та взаємодію з іншими AWS-сервісами.
