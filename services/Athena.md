# Amazon Athena

**Категорія:** Analytics  
**Призначення:** Serverless SQL-запити до даних, що зазвичай
зберігаються в Amazon S3.

## Словник термінів

| Термін                | Визначення українською                                                                                                                                 |
|-----------------------|--------------------------------------------------------------------------------------------------------------------------------------------------------|
| **Workgroup**         | Логічний контейнер Athena для ізоляції запитів, налаштувань, контролю витрат, доступу та розташування результатів.                                     |
| **Glue Data Catalog** | Центральний каталог метаданих AWS Glue з описами баз даних, таблиць, схем і розташуванням даних, які можуть використовувати Athena.                    |
| **External Table**    | Таблиця Athena, що містить метадані та схему файлів у зовнішньому сховищі (часто S3), але не копіює самі дані.                                         |
| **Partitioning**      | Поділ набору даних на частини за значеннями колонок, наприклад дата/регіон. Дозволяє Athena читати лише потрібні partitions і зменшувати scanned data. |
| **Parquet/ORC**       | Колонкові формати файлів, оптимізовані для аналітичних запитів. Зазвичай зменшують обсяг читання порівняно з текстовими форматами.                     |
| **Query Execution**   | Окремий запуск SQL-запиту Athena з унікальним QueryExecutionId, статусом, статистикою та результатом.                                                  |
| **Result Location**   | S3 bucket/prefix, куди Athena записує результати SQL-запиту та метадані виконання.                                                                     |
| **CTAS**              | CREATE TABLE AS SELECT — SQL-операція Athena, яка створює таблицю на основі результату SELECT, часто для перетворення даних у Parquet/ORC.             |
| **Federated Query**   | Можливість Athena запитувати дані в зовнішніх джерелах через data source connectors, а не лише файли в S3.                                             |

## Типовий екзаменаційний сценарій

SQL-аналітика файлів у S3 без розгортання БД → Athena.

## Екзаменаційна пастка

Оплата залежить від обсягу просканованих даних; фільтрація й
partitioning зменшують сканування. Glue Catalog зберігає метадані, не
самі файли.

## Як готуватися до цього сервісу

- Розпізнавайте, яку проблему сервіс вирішує, і коли його обирати
  замість альтернатив.
- Звертайте увагу на IAM permissions, resource policies та service
  roles.
- Розумійте event flow, retries, idempotency, throttling і dead-letter
  handling, якщо вони застосовні.
- Порівнюйте availability, consistency, scaling, latency та cost
  trade-offs.
