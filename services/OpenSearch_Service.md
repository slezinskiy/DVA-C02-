# Amazon OpenSearch Service

**Категорія:** Analytics

**Призначення:** Керований пошуковий та аналітичний рушій для
повнотекстового пошуку, логів і observability.

## Словник термінів

| Термін             | Визначення                                                                                                                           |
|--------------------|--------------------------------------------------------------------------------------------------------------------------------------|
| **Domain**         | Кероване середовище OpenSearch Service з налаштуваннями кластера.                                                                    |
| **Cluster**        | У контексті Amazon OpenSearch Service це поняття описує відповідний елемент сервісу, його налаштування або поведінку під час роботи. |
| **Node**           | У контексті Amazon OpenSearch Service це поняття описує відповідний елемент сервісу, його налаштування або поведінку під час роботи. |
| **Index**          | Логічна колекція документів, оптимізована для пошуку.                                                                                |
| **Document**       | JSON-подібний запис, який зберігається та індексується.                                                                              |
| **Mapping**        | Схема типів і властивостей полів документа.                                                                                          |
| **Inverted Index** | Структура, що зіставляє терміни з документами для швидкого пошуку.                                                                   |
| **Analyzer**       | Компонент токенізації та нормалізації тексту перед індексацією/пошуком.                                                              |
| **Shard**          | Логічна одиниця пропускної здатності й паралелізму потоку.                                                                           |
| **Replica**        | Копія shard або даних для доступності та масштабування читання.                                                                      |
| **Query DSL**      | JSON-формат для формування пошукових запитів OpenSearch.                                                                             |
| **Aggregation**    | Обчислення статистики, групувань і підсумків над результатами пошуку.                                                                |
| **Snapshot**       | Інкрементальна point-in-time резервна копія EBS volume, яка зберігається в AWS-managed storage.                                      |
| **Ingestion**      | У контексті Amazon OpenSearch Service це поняття описує відповідний елемент сервісу, його налаштування або поведінку під час роботи. |

## Типовий екзаменаційний сценарій

Потрібен повнотекстовий пошук або пошук по логах → OpenSearch.

## Екзаменаційна пастка

Не є транзакційною реляційною БД чи заміною DynamoDB для key-value
доступу.

## Що повторити

- Призначення сервісу та типові сценарії використання.
- Основні API, інтеграції та необхідні IAM permissions.
- Обробку помилок, retries, throttling і logging, якщо вони застосовні.
- Обмеження та взаємодію з іншими AWS-сервісами.
