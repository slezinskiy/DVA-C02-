# Amazon EBS

**Категорія:** Storage

**Призначення:** Блокове сховище, яке підключається до EC2 як
віртуальний диск.

## Словник термінів

| Термін                    | Визначення                                                                                                                                     |
|---------------------------|------------------------------------------------------------------------------------------------------------------------------------------------|
| **Volume**                | EBS блоковий том, який можна підключити до EC2.                                                                                                |
| **Snapshot**              | Інкрементальна point-in-time резервна копія EBS volume, яка зберігається в AWS-managed storage.                                                |
| **Volume Type**           | Клас EBS volume, що визначає характеристики ціни, IOPS, throughput і сценарій використання (наприклад gp3, io2, st1, sc1).                     |
| **IOPS**                  | Кількість операцій читання/запису за секунду; показник інтенсивності випадкового I/O.                                                          |
| **Throughput**            | Кількість даних, що передається за секунду; зазвичай вимірюється в MiB/s.                                                                      |
| **Latency**               | Час, потрібний для завершення операції вводу/виводу; важливий для чутливих до затримки workload.                                               |
| **Provisioned IOPS**      | Заздалегідь заданий рівень I/O operations per second, доступний у відповідних типах EBS volume.                                                |
| **Encryption**            | Шифрування EBS volume та snapshots за допомогою AWS KMS; зашифровані дані залишаються захищеними під час зберігання та передачі між EC2 і EBS. |
| **Multi-Attach**          | Можливість підключити один io1/io2 volume одночасно до кількох EC2 instances у межах однієї Availability Zone за підтримуваних конфігурацій.   |
| **Elastic Volumes**       | Можливість змінювати тип, розмір і продуктивність підтримуваного EBS volume без його від’єднання.                                              |
| **Root/Data Volume**      | Root volume містить ОС інстансу; data volume призначений для даних застосунку та може мати окремий життєвий цикл.                              |
| **AZ Scope**              | EBS volume є ресурсом однієї Availability Zone; для перенесення в іншу AZ використовують snapshot і створюють новий volume.                    |
| **Fast Snapshot Restore** | Функція, що усуває затримку ініціалізації блоків після створення volume зі snapshot у вибраній Availability Zone.                              |

## Типовий екзаменаційний сценарій

Потрібен постійний block device для EC2 → EBS.

## Екзаменаційна пастка

EBS volume прив’язаний до Availability Zone; для перенесення
використовують snapshot і створюють volume в іншій AZ.
