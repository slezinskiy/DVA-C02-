# AWS X-Ray

**Категорія:** Developer Tools

**Призначення:** Distributed tracing для аналізу шляху запиту через
сервіси.

## Словник термінів

| Термін              | Визначення                                                                                                           |
|---------------------|----------------------------------------------------------------------------------------------------------------------|
| **Trace**           | Повний шлях одного запиту через розподілену систему.                                                                 |
| **Segment**         | Дані про роботу окремого сервісу або компонента в trace.                                                             |
| **Subsegment**      | Деталізація внутрішньої операції segment.                                                                            |
| **Trace ID**        | У контексті AWS X-Ray це поняття описує відповідний елемент сервісу, його налаштування або поведінку під час роботи. |
| **Sampling**        | У контексті AWS X-Ray це поняття описує відповідний елемент сервісу, його налаштування або поведінку під час роботи. |
| **Sampling Rule**   | У контексті AWS X-Ray це поняття описує відповідний елемент сервісу, його налаштування або поведінку під час роботи. |
| **Annotation**      | Індексовані поля X-Ray, придатні для пошуку й фільтрації.                                                            |
| **Metadata**        | Додаткові дані trace, які не індексуються як annotations.                                                            |
| **Service Map**     | У контексті AWS X-Ray це поняття описує відповідний елемент сервісу, його налаштування або поведінку під час роботи. |
| **Trace Context**   | У контексті AWS X-Ray це поняття описує відповідний елемент сервісу, його налаштування або поведінку під час роботи. |
| **Instrumentation** | У контексті AWS X-Ray це поняття описує відповідний елемент сервісу, його налаштування або поведінку під час роботи. |

## Типовий екзаменаційний сценарій

Потрібно знайти, який сервіс спричиняє latency у distributed request →
X-Ray.

## Екзаменаційна пастка

CloudWatch — metrics/logs/alarms; X-Ray — trace одного запиту та
залежностей.

## Що повторити

- Призначення сервісу та типові сценарії використання.
- Основні API, інтеграції та необхідні IAM permissions.
- Обробку помилок, retries, throttling і logging, якщо вони застосовні.
- Обмеження та взаємодію з іншими AWS-сервісами.
