# AWS AppSync

**Категорія:** Application Integration

**Призначення:** Керований GraphQL API, що об’єднує джерела даних і
підтримує realtime subscriptions.

## Словник термінів

| Термін                 | Визначення                                                                                                             |
|------------------------|------------------------------------------------------------------------------------------------------------------------|
| **GraphQL**            | Мова запитів до API, де клієнт описує потрібну структуру відповіді.                                                    |
| **Schema**             | Контракт GraphQL API з типами, полями, аргументами та операціями.                                                      |
| **Query**              | Операція читання даних у GraphQL.                                                                                      |
| **Mutation**           | Операція зміни даних у GraphQL.                                                                                        |
| **Subscription**       | Зв’язок між SNS topic і subscriber endpoint.                                                                           |
| **Resolver**           | Компонент, який пов’язує поле API з логікою або джерелом даних.                                                        |
| **Data Source**        | Backend-ресурс, з якого API читає або в який записує дані.                                                             |
| **Pipeline Resolver**  | Resolver, який виконує кілька функцій послідовно.                                                                      |
| **VTL**                | У контексті AWS AppSync це поняття описує відповідний елемент сервісу, його налаштування або поведінку під час роботи. |
| **APPSYNC_JS**         | У контексті AWS AppSync це поняття описує відповідний елемент сервісу, його налаштування або поведінку під час роботи. |
| **Authorization Mode** | У контексті AWS AppSync це поняття описує відповідний елемент сервісу, його налаштування або поведінку під час роботи. |
| **Conflict Detection** | У контексті AWS AppSync це поняття описує відповідний елемент сервісу, його налаштування або поведінку під час роботи. |

## Типовий екзаменаційний сценарій

Клієнту потрібен GraphQL API з realtime оновленнями → AppSync.

## Екзаменаційна пастка

GraphQL — API-модель, не база даних. User Pool і IAM — різні режими
авторизації.

## Що повторити

- Призначення сервісу та типові сценарії використання.
- Основні API, інтеграції та необхідні IAM permissions.
- Обробку помилок, retries, throttling і logging, якщо вони застосовні.
- Обмеження та взаємодію з іншими AWS-сервісами.
