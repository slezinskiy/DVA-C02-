# Amazon SNS

**Категорія:** Application Integration

**Призначення:** Pub/sub сервіс для fan-out повідомлень багатьом
підписникам.

## Словник термінів

| Термін                   | Визначення                                                                                                            |
|--------------------------|-----------------------------------------------------------------------------------------------------------------------|
| **Topic**                | Логічний канал, у який publisher надсилає повідомлення.                                                               |
| **Publisher**            | Відправник, який публікує повідомлення в SNS topic.                                                                   |
| **Subscriber**           | Endpoint, який отримує повідомлення з SNS topic.                                                                      |
| **Subscription**         | Зв’язок між SNS topic і subscriber endpoint.                                                                          |
| **Fan-out**              | Передача одного повідомлення кільком незалежним підписникам.                                                          |
| **Message Attributes**   | Метадані повідомлення, які можуть використовуватися для фільтрації.                                                   |
| **Filter Policy**        | Умова, за якою SNS вирішує, чи доставляти повідомлення певній subscription.                                           |
| **Raw Message Delivery** | У контексті Amazon SNS це поняття описує відповідний елемент сервісу, його налаштування або поведінку під час роботи. |
| **FIFO Topic**           | У контексті Amazon SNS це поняття описує відповідний елемент сервісу, його налаштування або поведінку під час роботи. |
| **Deduplication**        | У контексті Amazon SNS це поняття описує відповідний елемент сервісу, його налаштування або поведінку під час роботи. |
| **Delivery Policy**      | У контексті Amazon SNS це поняття описує відповідний елемент сервісу, його налаштування або поведінку під час роботи. |
| **DLQ**                  | У контексті Amazon SNS це поняття описує відповідний елемент сервісу, його налаштування або поведінку під час роботи. |

## Типовий екзаменаційний сценарій

Одне повідомлення потрібно доставити кільком незалежним споживачам →
SNS.

## Екзаменаційна пастка

SNS не є чергою для довготривалого споживання. Часто поєднується з
окремою SQS queue для кожного consumer.

## Що повторити

- Призначення сервісу та типові сценарії використання.
- Основні API, інтеграції та необхідні IAM permissions.
- Обробку помилок, retries, throttling і logging, якщо вони застосовні.
- Обмеження та взаємодію з іншими AWS-сервісами.
