# Storage — довідник DVA-C02

Ключові поняття, сценарії та типові екзаменаційні пастки для сервісів
цієї категорії.

## Amazon EBS

**Призначення:** Блокове сховище, яке підключається до EC2 як
віртуальний диск.

### Ключові терміни

| Термін                    | Визначення                                                                                                                                     |
|---------------------------|------------------------------------------------------------------------------------------------------------------------------------------------|
| **Volume**                | EBS блоковий том, який можна підключити до EC2.                                                                                                |
| **Snapshot**              | Інкрементальна point-in-time резервна копія EBS volume, яка зберігається в AWS-managed storage.                                                |
| **Volume Type**           | Клас EBS volume, що визначає характеристики ціни, IOPS, throughput і сценарій використання (наприклад gp3, io2, st1, sc1).                     |
| **IOPS**                  | Кількість операцій читання/запису за секунду; показник інтенсивності випадкового I/O.                                                          |
| **Throughput**            | Кількість даних, що передається за секунду; зазвичай вимірюється в MiB/s.                                                                      |
| **Latency**               | Час, потрібний для завершення операції вводу/виводу; важливий для чутливих до затримки workload.                                               |
| **Provisioned IOPS**      | Заздалегідь заданий рівень I/O operations per second, доступний у відповідних типах EBS volume.                                                |
| **Encryption**            | Шифрування EBS volume та snapshots за допомогою AWS KMS; зашифровані дані залишаються захищеними під час зберігання та передачі між EC2 і EBS. |
| **Multi-Attach**          | Можливість підключити один io1/io2 volume одночасно до кількох EC2 instances у межах однієї Availability Zone за підтримуваних конфігурацій.   |
| **Elastic Volumes**       | Можливість змінювати тип, розмір і продуктивність підтримуваного EBS volume без його від’єднання.                                              |
| **Root/Data Volume**      | Root volume містить ОС інстансу; data volume призначений для даних застосунку та може мати окремий життєвий цикл.                              |
| **AZ Scope**              | EBS volume є ресурсом однієї Availability Zone; для перенесення в іншу AZ використовують snapshot і створюють новий volume.                    |
| **Fast Snapshot Restore** | Функція, що усуває затримку ініціалізації блоків після створення volume зі snapshot у вибраній Availability Zone.                              |

**Типовий екзаменаційний сценарій:** Потрібен постійний block device для
EC2 → EBS.

**Екзаменаційна пастка:** EBS volume прив’язаний до Availability Zone;
для перенесення використовують snapshot і створюють volume в іншій AZ.

## Amazon EFS

**Призначення:** Еластична спільна мережева файлова система для Linux
workloads.

### Ключові терміни

| Термін                     | Визначення                                                                                                                                     |
|----------------------------|------------------------------------------------------------------------------------------------------------------------------------------------|
| **File System**            | У контексті Amazon EFS це поняття описує відповідний елемент сервісу, його налаштування або поведінку під час роботи.                          |
| **Mount Target**           | Мережевий endpoint для монтування EFS у VPC/AZ.                                                                                                |
| **NFS**                    | У контексті Amazon EFS це поняття описує відповідний елемент сервісу, його налаштування або поведінку під час роботи.                          |
| **Access Point**           | EFS endpoint із визначеним root directory та POSIX identity settings.                                                                          |
| **POSIX Permissions**      | У контексті Amazon EFS це поняття описує відповідний елемент сервісу, його налаштування або поведінку під час роботи.                          |
| **UID/GID**                | У контексті Amazon EFS це поняття описує відповідний елемент сервісу, його налаштування або поведінку під час роботи.                          |
| **Performance Mode**       | У контексті Amazon EFS це поняття описує відповідний елемент сервісу, його налаштування або поведінку під час роботи.                          |
| **Throughput Mode**        | У контексті Amazon EFS це поняття описує відповідний елемент сервісу, його налаштування або поведінку під час роботи.                          |
| **Bursting**               | У контексті Amazon EFS це поняття описує відповідний елемент сервісу, його налаштування або поведінку під час роботи.                          |
| **Elastic Throughput**     | У контексті Amazon EFS це поняття описує відповідний елемент сервісу, його налаштування або поведінку під час роботи.                          |
| **Provisioned Throughput** | У контексті Amazon EFS це поняття описує відповідний елемент сервісу, його налаштування або поведінку під час роботи.                          |
| **Lifecycle Management**   | У контексті Amazon EFS це поняття описує відповідний елемент сервісу, його налаштування або поведінку під час роботи.                          |
| **IA**                     | У контексті Amazon EFS це поняття описує відповідний елемент сервісу, його налаштування або поведінку під час роботи.                          |
| **One Zone**               | У контексті Amazon EFS це поняття описує відповідний елемент сервісу, його налаштування або поведінку під час роботи.                          |
| **Encryption**             | Шифрування EBS volume та snapshots за допомогою AWS KMS; зашифровані дані залишаються захищеними під час зберігання та передачі між EC2 і EBS. |

**Типовий екзаменаційний сценарій:** Кілька Linux instances потребують
спільної файлової системи → EFS.

**Екзаменаційна пастка:** EFS — file storage через NFS; EBS — block
storage для instance; S3 — object storage.

## Amazon S3

**Призначення:** Об’єктне сховище для файлів, backup, data lakes, static
content та інтеграцій.

### Ключові терміни

| Термін                    | Визначення                                                                                                           |
|---------------------------|----------------------------------------------------------------------------------------------------------------------|
| **Bucket**                | S3 контейнер об’єктів.                                                                                               |
| **Object**                | S3 дані разом із metadata.                                                                                           |
| **Key**                   | Унікальне ім’я об’єкта в межах S3 bucket.                                                                            |
| **Prefix**                | У контексті Amazon S3 це поняття описує відповідний елемент сервісу, його налаштування або поведінку під час роботи. |
| **Bucket Policy**         | У контексті Amazon S3 це поняття описує відповідний елемент сервісу, його налаштування або поведінку під час роботи. |
| **ACL**                   | У контексті Amazon S3 це поняття описує відповідний елемент сервісу, його налаштування або поведінку під час роботи. |
| **Block Public Access**   | Набір S3 налаштувань, що блокує небажаний публічний доступ.                                                          |
| **Versioning**            | Збереження кількох версій об’єкта з однаковим key.                                                                   |
| **Delete Marker**         | У контексті Amazon S3 це поняття описує відповідний елемент сервісу, його налаштування або поведінку під час роботи. |
| **Lifecycle**             | У контексті Amazon S3 це поняття описує відповідний елемент сервісу, його налаштування або поведінку під час роботи. |
| **Storage Class**         | У контексті Amazon S3 це поняття описує відповідний елемент сервісу, його налаштування або поведінку під час роботи. |
| **Glacier**               | У контексті Amazon S3 це поняття описує відповідний елемент сервісу, його налаштування або поведінку під час роботи. |
| **Replication**           | У контексті Amazon S3 це поняття описує відповідний елемент сервісу, його налаштування або поведінку під час роботи. |
| **CRR/SRR**               | У контексті Amazon S3 це поняття описує відповідний елемент сервісу, його налаштування або поведінку під час роботи. |
| **Multipart Upload**      | Завантаження великого об’єкта окремими частинами.                                                                    |
| **Presigned URL**         | Тимчасовий підписаний URL для доступу до S3 object.                                                                  |
| **Event Notification**    | У контексті Amazon S3 це поняття описує відповідний елемент сервісу, його налаштування або поведінку під час роботи. |
| **Object Lock**           | WORM-механізм захисту об’єктів від видалення/перезапису.                                                             |
| **SSE-S3**                | У контексті Amazon S3 це поняття описує відповідний елемент сервісу, його налаштування або поведінку під час роботи. |
| **SSE-KMS**               | У контексті Amazon S3 це поняття описує відповідний елемент сервісу, його налаштування або поведінку під час роботи. |
| **SSE-C**                 | У контексті Amazon S3 це поняття описує відповідний елемент сервісу, його налаштування або поведінку під час роботи. |
| **Transfer Acceleration** | У контексті Amazon S3 це поняття описує відповідний елемент сервісу, його налаштування або поведінку під час роботи. |
| **Access Point**          | EFS endpoint із визначеним root directory та POSIX identity settings.                                                |
| **Inventory**             | У контексті Amazon S3 це поняття описує відповідний елемент сервісу, його налаштування або поведінку під час роботи. |
| **Storage Lens**          | У контексті Amazon S3 це поняття описує відповідний елемент сервісу, його налаштування або поведінку під час роботи. |
| **ETag**                  | У контексті Amazon S3 це поняття описує відповідний елемент сервісу, його налаштування або поведінку під час роботи. |

**Типовий екзаменаційний сценарій:** Потрібне масштабоване object
storage або статичний контент → S3.

**Екзаменаційна пастка:** S3 має strong read-after-write consistency для
PUT/DELETE. ETag не завжди дорівнює MD5; приватний CloudFront origin
захищайте OAC.
