## Amazon CloudFront

**Призначення:** Глобальна CDN для кешування та доставки контенту через
edge locations.

| **Origin**                | Джерело контенту, з якого CloudFront отримує об’єкти.                                                                        |
| **Edge Location**         | У контексті Amazon CloudFront це поняття описує відповідний елемент сервісу, його налаштування або поведінку під час роботи. |
| **Regional Edge Cache**   | У контексті Amazon CloudFront це поняття описує відповідний елемент сервісу, його налаштування або поведінку під час роботи. |
| **Cache Behavior**        | У контексті Amazon CloudFront це поняття описує відповідний елемент сервісу, його налаштування або поведінку під час роботи. |
| **Cache Policy**          | Визначає cache key та TTL-поведінку CloudFront.                                                                              |
| **Origin Request Policy** | У контексті Amazon CloudFront це поняття описує відповідний елемент сервісу, його налаштування або поведінку під час роботи. |
| **TTL**                   | У контексті Amazon CloudFront це поняття описує відповідний елемент сервісу, його налаштування або поведінку під час роботи. |

| **Lambda@Edge**           | У контексті Amazon CloudFront це поняття описує відповідний елемент сервісу, його налаштування або поведінку під час роботи. |

| Термін                   | Визначення                                                                                                                        |
|--------------------------|-----------------------------------------------------------------------------------------------------------------------------------|

| **NLB**                  | У контексті Elastic Load Balancing це поняття описує відповідний елемент сервісу, його налаштування або поведінку під час роботи. |
| **GWLB**                 | У контексті Elastic Load Balancing це поняття описує відповідний елемент сервісу, його налаштування або поведінку під час роботи. |
| **CLB**                  | У контексті Elastic Load Balancing це поняття описує відповідний елемент сервісу, його налаштування або поведінку під час роботи. |
| **Listener**             | Компонент load balancer, який приймає з’єднання на protocol/port.                                                                 |
| **Listener Rule**        | У контексті Elastic Load Balancing це поняття описує відповідний елемент сервісу, його налаштування або поведінку під час роботи. |
| **Target Group**         | Набір backend targets, до яких load balancer маршрутизує трафік.                                                                  |

| **Deregistration Delay** | У контексті Elastic Load Balancing це поняття описує відповідний елемент сервісу, його налаштування або поведінку під час роботи. |

| **SNI**                  | У контексті Elastic Load Balancing це поняття описує відповідний елемент сервісу, його налаштування або поведінку під час роботи. |

**Типовий екзаменаційний сценарій:** HTTP path/host routing → ALB;
TCP/UDP/TLS high-performance routing → NLB.

**Екзаменаційна пастка:** ALB — Layer 7; NLB — Layer 4. Health checks
визначають healthy targets.
