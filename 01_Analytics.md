# Analytics — довідник DVA-C02

Ключові поняття, сценарії та типові екзаменаційні пастки для сервісів
цієї категорії.

## Amazon Athena

**Призначення:** Serverless SQL-запити до даних, що зазвичай
зберігаються в Amazon S3.

### Ключові терміни

| Термін                | Визначення                                                                              |
|-----------------------|-----------------------------------------------------------------------------------------|
| **Workgroup**         | Логічна група запитів Athena для керування налаштуваннями, доступом і витратами.        |
| **Glue Data Catalog** | Центральний каталог метаданих таблиць, схем і розташування наборів даних.               |
| **External Table**    | Опис структури зовнішніх даних, які фізично залишаються у сховищі на кшталт S3.         |
| **Partitioning**      | Поділ набору даних за значеннями колонок, щоб запит читав лише потрібні частини.        |
| **Parquet/ORC**       | Колонкові формати зберігання, що часто зменшують обсяг читання для аналітичних запитів. |
| **Query Execution**   | Окремий запуск SQL-запиту з власним execution ID і статусом.                            |
| **Result Location**   | S3-розташування, куди записуються результати запитів Athena.                            |
| **CTAS**              | SQL-операція створення нової таблиці на основі результату SELECT.                       |
| **Federated Query**   | Запит до зовнішнього джерела через конектор, а не лише до файлів S3.                    |

**Типовий екзаменаційний сценарій:** SQL-аналітика файлів у S3 без
розгортання БД → Athena.

**Екзаменаційна пастка:** Оплата залежить від обсягу просканованих
даних; фільтрація й partitioning зменшують сканування. Glue Catalog
зберігає метадані, не самі файли.

## Amazon Kinesis

**Призначення:** Сімейство сервісів для приймання, потокової обробки та
доставки подій.

### Ключові терміни

| Термін               | Визначення                                                                                                |
|----------------------|-----------------------------------------------------------------------------------------------------------|
| **Data Streams**     | Сервіс потоку записів, який дозволяє власним consumer читати та обробляти події.                          |
| **Data Firehose**    | Керована доставка потокових даних до призначення з буферизацією та опційною трансформацією.               |
| **Producer**         | Компонент, який записує повідомлення або події в потік.                                                   |
| **Consumer**         | Компонент, який читає та обробляє повідомлення або події.                                                 |
| **Shard**            | Логічна одиниця пропускної здатності й паралелізму потоку.                                                |
| **Partition Key**    | Значення, за яким потік розподіляє записи між shard.                                                      |
| **Sequence Number**  | Порядковий ідентифікатор запису в межах shard.                                                            |
| **Retention**        | Період, протягом якого записи залишаються доступними для читання.                                         |
| **Enhanced Fan-Out** | Модель читання, що надає consumer виділену пропускну здатність.                                           |
| **KCL**              | Kinesis Client Library — бібліотека для координованої обробки shard, checkpoint та балансування consumer. |
| **Checkpoint**       | Збережена позиція обробки, з якої consumer може продовжити читання.                                       |
| **Resharding**       | Зміна кількості shard для зміни пропускної здатності й паралелізму.                                       |
| **Buffering**        | Накопичення записів до досягнення заданого розміру або часу перед доставкою.                              |

**Типовий екзаменаційний сценарій:** Потрібен контроль consumer та
повторне читання потоку → Data Streams; потрібна керована доставка в S3
→ Firehose.

**Екзаменаційна пастка:** Kinesis Streams — журнал потоку для consumer;
SQS — черга повідомлень. Не плутати Data Streams із Data Firehose.

## Amazon OpenSearch Service

**Призначення:** Керований пошуковий та аналітичний рушій для
повнотекстового пошуку, логів і observability.

### Ключові терміни

| Термін             | Визначення                                                                                                                           |
|--------------------|--------------------------------------------------------------------------------------------------------------------------------------|
| **Domain**         | Кероване середовище OpenSearch Service з налаштуваннями кластера.                                                                    |
| **Cluster**        | У контексті Amazon OpenSearch Service це поняття описує відповідний елемент сервісу, його налаштування або поведінку під час роботи. |
| **Node**           | У контексті Amazon OpenSearch Service це поняття описує відповідний елемент сервісу, його налаштування або поведінку під час роботи. |
| **Index**          | Логічна колекція документів, оптимізована для пошуку.                                                                                |
| **Document**       | JSON-подібний запис, який зберігається та індексується.                                                                              |
| **Mapping**        | Схема типів і властивостей полів документа.                                                                                          |
| **Inverted Index** | Структура, що зіставляє терміни з документами для швидкого пошуку.                                                                   |
| **Analyzer**       | Компонент токенізації та нормалізації тексту перед індексацією/пошуком.                                                              |
| **Shard**          | Логічна одиниця пропускної здатності й паралелізму потоку.                                                                           |
| **Replica**        | Копія shard або даних для доступності та масштабування читання.                                                                      |
| **Query DSL**      | JSON-формат для формування пошукових запитів OpenSearch.                                                                             |
| **Aggregation**    | Обчислення статистики, групувань і підсумків над результатами пошуку.                                                                |
| **Snapshot**       | Інкрементальна point-in-time резервна копія EBS volume, яка зберігається в AWS-managed storage.                                      |
| **Ingestion**      | У контексті Amazon OpenSearch Service це поняття описує відповідний елемент сервісу, його налаштування або поведінку під час роботи. |

**Типовий екзаменаційний сценарій:** Потрібен повнотекстовий пошук або
пошук по логах → OpenSearch.

**Екзаменаційна пастка:** Не є транзакційною реляційною БД чи заміною
DynamoDB для key-value доступу.
