## AWS X-Ray

**Призначення:** Distributed tracing для аналізу шляху запиту через
сервіси. \### Ключові терміни \| Термін \| Визначення \| \|---\|---\| \|
**Trace** \| Повний шлях одного запиту через розподілену систему. \| \|
**Segment** \| Дані про роботу окремого сервісу або компонента в trace.
\| \| **Subsegment** \| Деталізація внутрішньої операції segment. \| \|
**Trace ID** \| Ключовий компонент або поняття AWS X-Ray; визначає
відповідну частину конфігурації, виконання чи інтеграції сервісу. \| \|
**Sampling** \| Ключовий компонент або поняття AWS X-Ray; визначає
відповідну частину конфігурації, виконання чи інтеграції сервісу. \| \|
**Sampling Rule** \| Ключовий компонент або поняття AWS X-Ray; визначає
відповідну частину конфігурації, виконання чи інтеграції сервісу. \| \|
**Annotation** \| Індексовані поля X-Ray, придатні для пошуку й
фільтрації. \| \| **Metadata** \| Додаткові дані trace, які не
індексуються як annotations. \| \| **Service Map** \| Ключовий компонент
або поняття AWS X-Ray; визначає відповідну частину конфігурації,
виконання чи інтеграції сервісу. \| \| **Trace Context** \| Ключовий
компонент або поняття AWS X-Ray; визначає відповідну частину
конфігурації, виконання чи інтеграції сервісу. \| \| **Instrumentation**
\| Ключовий компонент або поняття AWS X-Ray; визначає відповідну частину
конфігурації, виконання чи інтеграції сервісу. \|

**Типовий екзаменаційний сценарій:** Потрібно знайти, який сервіс
спричиняє latency у distributed request → X-Ray.

**Екзаменаційна пастка:** CloudWatch --- metrics/logs/alarms; X-Ray ---
trace одного запиту та залежностей.
