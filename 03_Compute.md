# Compute — довідник DVA-C02

Ключові поняття, сценарії та типові екзаменаційні пастки для сервісів
цієї категорії.

## Amazon EC2

**Призначення:** Віртуальні сервери з повним контролем над ОС, типом
інстансу та програмним середовищем.

### Ключові терміни

| Термін                   | Визначення                                                                                                            |
|--------------------------|-----------------------------------------------------------------------------------------------------------------------|
| **Instance**             | У контексті Amazon EC2 це поняття описує відповідний елемент сервісу, його налаштування або поведінку під час роботи. |
| **AMI**                  | Шаблон образу, з якого запускають EC2 instance.                                                                       |
| **Instance Type/Family** | У контексті Amazon EC2 це поняття описує відповідний елемент сервісу, його налаштування або поведінку під час роботи. |
| **User Data**            | Bootstrap-скрипт або конфігурація, що передається інстансу під час запуску.                                           |
| **Metadata**             | Додаткові дані trace, які не індексуються як annotations.                                                             |
| **IMDSv2**               | Захищеніший режим Instance Metadata Service, який використовує session token.                                         |
| **Instance Profile**     | Контейнер, через який IAM Role прикріплюється до EC2 instance.                                                        |
| **Security Group**       | Stateful virtual firewall на рівні мережевого інтерфейсу ресурсу.                                                     |
| **EBS**                  | У контексті Amazon EC2 це поняття описує відповідний елемент сервісу, його налаштування або поведінку під час роботи. |
| **Instance Store**       | У контексті Amazon EC2 це поняття описує відповідний елемент сервісу, його налаштування або поведінку під час роботи. |
| **Placement Group**      | У контексті Amazon EC2 це поняття описує відповідний елемент сервісу, його налаштування або поведінку під час роботи. |
| **ASG**                  | У контексті Amazon EC2 це поняття описує відповідний елемент сервісу, його налаштування або поведінку під час роботи. |
| **Launch Template**      | Шаблон параметрів запуску EC2 instance.                                                                               |
| **Spot**                 | Модель використання вільної EC2 capacity зі знижкою, але з ризиком переривання.                                       |
| **On-Demand**            | У контексті Amazon EC2 це поняття описує відповідний елемент сервісу, його налаштування або поведінку під час роботи. |
| **Savings Plans**        | У контексті Amazon EC2 це поняття описує відповідний елемент сервісу, його налаштування або поведінку під час роботи. |
| **Elastic IP**           | У контексті Amazon EC2 це поняття описує відповідний елемент сервісу, його налаштування або поведінку під час роботи. |
| **ENI**                  | У контексті Amazon EC2 це поняття описує відповідний елемент сервісу, його налаштування або поведінку під час роботи. |

**Типовий екзаменаційний сценарій:** Потрібен контроль над ОС, агентами
або довготривалим процесом → EC2.

**Екзаменаційна пастка:** IAM Role через Instance Profile краще за
статичні access keys. Stop зберігає інстанс; Terminate видаляє його.

## AWS Elastic Beanstalk

**Призначення:** PaaS-подібний сервіс розгортання застосунків із
керуванням середовищем та базовими AWS-ресурсами.

### Ключові терміни

| Термін                     | Визначення                                                                                                                       |
|----------------------------|----------------------------------------------------------------------------------------------------------------------------------|
| **Application**            | У контексті AWS Elastic Beanstalk це поняття описує відповідний елемент сервісу, його налаштування або поведінку під час роботи. |
| **Application Version**    | Завантажений пакет коду Beanstalk, який можна розгортати.                                                                        |
| **Environment**            | Набір AWS-ресурсів, на якому працює версія застосунку Beanstalk.                                                                 |
| **Web/Worker Tier**        | У контексті AWS Elastic Beanstalk це поняття описує відповідний елемент сервісу, його налаштування або поведінку під час роботи. |
| **Platform**               | У контексті AWS Elastic Beanstalk це поняття описує відповідний елемент сервісу, його налаштування або поведінку під час роботи. |
| **Configuration Template** | У контексті AWS Elastic Beanstalk це поняття описує відповідний елемент сервісу, його налаштування або поведінку під час роботи. |
| **Environment Variables**  | У контексті AWS Elastic Beanstalk це поняття описує відповідний елемент сервісу, його налаштування або поведінку під час роботи. |
| **.ebextensions**          | У контексті AWS Elastic Beanstalk це поняття описує відповідний елемент сервісу, його налаштування або поведінку під час роботи. |
| **.platform**              | У контексті AWS Elastic Beanstalk це поняття описує відповідний елемент сервісу, його налаштування або поведінку під час роботи. |
| **Rolling**                | У контексті AWS Elastic Beanstalk це поняття описує відповідний елемент сервісу, його налаштування або поведінку під час роботи. |
| **Immutable**              | У контексті AWS Elastic Beanstalk це поняття описує відповідний елемент сервісу, його налаштування або поведінку під час роботи. |
| **Blue/Green**             | У контексті AWS Elastic Beanstalk це поняття описує відповідний елемент сервісу, його налаштування або поведінку під час роботи. |
| **All-at-once**            | У контексті AWS Elastic Beanstalk це поняття описує відповідний елемент сервісу, його налаштування або поведінку під час роботи. |

**Типовий екзаменаційний сценарій:** Потрібно розгорнути web app без
ручного створення всіх EC2/ELB/ASG компонентів → Elastic Beanstalk.

**Екзаменаційна пастка:** Beanstalk керує середовищем, але не є окремою
мовою чи runtime. Worker environment часто інтегрується із SQS.

## AWS Lambda

**Призначення:** Serverless compute для виконання коду у відповідь на
події або API-виклики.

### Ключові терміни

| Термін                      | Визначення                                                                                                            |
|-----------------------------|-----------------------------------------------------------------------------------------------------------------------|
| **Function**                | У контексті AWS Lambda це поняття описує відповідний елемент сервісу, його налаштування або поведінку під час роботи. |
| **Handler**                 | Функція-точка входу, яку Lambda викликає для обробки події.                                                           |
| **Runtime**                 | Середовище виконання мови програмування у Lambda.                                                                     |
| **Invocation**              | Один виклик Lambda function.                                                                                          |
| **Event**                   | Повідомлення про факт або зміну, що сталася.                                                                          |
| **Context**                 | У контексті AWS Lambda це поняття описує відповідний елемент сервісу, його налаштування або поведінку під час роботи. |
| **Execution Role**          | IAM Role, яку Lambda assume для доступу до інших AWS resources.                                                       |
| **Resource Policy**         | Політика на самій Lambda function, що визначає, хто може її викликати.                                                |
| **Timeout**                 | У контексті AWS Lambda це поняття описує відповідний елемент сервісу, його налаштування або поведінку під час роботи. |
| **Memory**                  | У контексті AWS Lambda це поняття описує відповідний елемент сервісу, його налаштування або поведінку під час роботи. |
| **/tmp**                    | У контексті AWS Lambda це поняття описує відповідний елемент сервісу, його налаштування або поведінку під час роботи. |
| **Layer**                   | Пакет спільних бібліотек або файлів, які підключаються до Lambda function.                                            |
| **Version**                 | Незмінний snapshot коду та конфігурації Lambda.                                                                       |
| **Alias**                   | Іменований покажчик на конкретну версію Lambda.                                                                       |
| **Reserved Concurrency**    | Резерв concurrency для функції та верхнє обмеження її одночасних викликів.                                            |
| **Provisioned Concurrency** | Попередньо ініціалізовані execution environments для зменшення cold starts.                                           |
| **Cold Start**              | Додаткова затримка створення нового execution environment.                                                            |
| **Event Source Mapping**    | Керований poller, що читає події із джерела та передає їх Lambda.                                                     |
| **DLQ**                     | У контексті AWS Lambda це поняття описує відповідний елемент сервісу, його налаштування або поведінку під час роботи. |
| **Destinations**            | У контексті AWS Lambda це поняття описує відповідний елемент сервісу, його налаштування або поведінку під час роботи. |
| **VPC**                     | У контексті AWS Lambda це поняття описує відповідний елемент сервісу, його налаштування або поведінку під час роботи. |
| **SnapStart**               | У контексті AWS Lambda це поняття описує відповідний елемент сервісу, його налаштування або поведінку під час роботи. |
| **Function URL**            | У контексті AWS Lambda це поняття описує відповідний елемент сервісу, його налаштування або поведінку під час роботи. |

**Типовий екзаменаційний сценарій:** Подієвий код без керування
серверами → Lambda.

**Екзаменаційна пастка:** Execution Role визначає доступ функції до AWS;
resource policy визначає, хто може її викликати. Reserved і Provisioned
Concurrency — різні речі.
