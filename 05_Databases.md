# Database — довідник DVA-C02

Ключові поняття, сценарії та типові екзаменаційні пастки для сервісів
цієї категорії.

## Amazon Aurora

**Призначення:** Реляційна БД, сумісна з MySQL/PostgreSQL, з cluster
storage та writer/reader instances.

### Ключові терміни

| Термін                    | Визначення                                                                                                               |
|---------------------------|--------------------------------------------------------------------------------------------------------------------------|
| **DB Cluster**            | У контексті Amazon Aurora це поняття описує відповідний елемент сервісу, його налаштування або поведінку під час роботи. |
| **Writer**                | У контексті Amazon Aurora це поняття описує відповідний елемент сервісу, його налаштування або поведінку під час роботи. |
| **Reader**                | У контексті Amazon Aurora це поняття описує відповідний елемент сервісу, його налаштування або поведінку під час роботи. |
| **Cluster Endpoint**      | Aurora endpoint, що спрямовує з’єднання до поточного writer.                                                             |
| **Reader Endpoint**       | Aurora endpoint для розподілу read-only з’єднань між reader instances.                                                   |
| **Instance Endpoint**     | У контексті Amazon Aurora це поняття описує відповідний елемент сервісу, його налаштування або поведінку під час роботи. |
| **Shared Cluster Volume** | У контексті Amazon Aurora це поняття описує відповідний елемент сервісу, його налаштування або поведінку під час роботи. |
| **Aurora Replica**        | У контексті Amazon Aurora це поняття описує відповідний елемент сервісу, його налаштування або поведінку під час роботи. |
| **Failover**              | У контексті Amazon Aurora це поняття описує відповідний елемент сервісу, його налаштування або поведінку під час роботи. |
| **Global Database**       | У контексті Amazon Aurora це поняття описує відповідний елемент сервісу, його налаштування або поведінку під час роботи. |
| **Serverless v2**         | У контексті Amazon Aurora це поняття описує відповідний елемент сервісу, його налаштування або поведінку під час роботи. |
| **Backtrack**             | У контексті Amazon Aurora це поняття описує відповідний елемент сервісу, його налаштування або поведінку під час роботи. |
| **Parameter Group**       | У контексті Amazon Aurora це поняття описує відповідний елемент сервісу, його налаштування або поведінку під час роботи. |
| **RDS Proxy**             | У контексті Amazon Aurora це поняття описує відповідний елемент сервісу, його налаштування або поведінку під час роботи. |
| **Snapshot**              | Інкрементальна point-in-time резервна копія EBS volume, яка зберігається в AWS-managed storage.                          |

**Типовий екзаменаційний сценарій:** Потрібна керована реляційна БД із
високою доступністю та read replicas → Aurora.

**Екзаменаційна пастка:** Reader endpoint спрямовує read connections;
cluster endpoint — до writer. Не плутати Aurora Replica із DynamoDB
Global Tables.

## Amazon ElastiCache

**Призначення:** Керований in-memory cache для зменшення latency та
навантаження на бази даних.

### Ключові терміни

| Термін                | Визначення                                                                                                                    |
|-----------------------|-------------------------------------------------------------------------------------------------------------------------------|
| **Valkey/Redis OSS**  | У контексті Amazon ElastiCache це поняття описує відповідний елемент сервісу, його налаштування або поведінку під час роботи. |
| **Memcached**         | У контексті Amazon ElastiCache це поняття описує відповідний елемент сервісу, його налаштування або поведінку під час роботи. |
| **Cache Hit/Miss**    | У контексті Amazon ElastiCache це поняття описує відповідний елемент сервісу, його налаштування або поведінку під час роботи. |
| **Cache Aside**       | Патерн, де застосунок спочатку читає кеш, а при miss завантажує дані з БД і кешує їх.                                         |
| **Lazy Loading**      | У контексті Amazon ElastiCache це поняття описує відповідний елемент сервісу, його налаштування або поведінку під час роботи. |
| **Write-through**     | У контексті Amazon ElastiCache це поняття описує відповідний елемент сервісу, його налаштування або поведінку під час роботи. |
| **TTL**               | У контексті Amazon ElastiCache це поняття описує відповідний елемент сервісу, його налаштування або поведінку під час роботи. |
| **Eviction**          | Видалення ключів із кешу за політикою, часто через нестачу пам’яті.                                                           |
| **Node**              | У контексті Amazon ElastiCache це поняття описує відповідний елемент сервісу, його налаштування або поведінку під час роботи. |
| **Shard**             | Логічна одиниця пропускної здатності й паралелізму потоку.                                                                    |
| **Replication Group** | У контексті Amazon ElastiCache це поняття описує відповідний елемент сервісу, його налаштування або поведінку під час роботи. |
| **Cluster Mode**      | У контексті Amazon ElastiCache це поняття описує відповідний елемент сервісу, його налаштування або поведінку під час роботи. |
| **Multi-AZ**          | Розміщення компонентів у кількох Availability Zones для доступності.                                                          |
| **Failover**          | У контексті Amazon ElastiCache це поняття описує відповідний елемент сервісу, його налаштування або поведінку під час роботи. |

**Типовий екзаменаційний сценарій:** Потрібен загальний кеш для
застосунку або сесій → ElastiCache.

**Екзаменаційна пастка:** DAX спеціалізований для DynamoDB; ElastiCache
— загальний кеш для різних застосунків.
