# Security, Identity, and Compliance — довідник DVA-C02

Ключові поняття, сценарії та типові екзаменаційні пастки для сервісів
цієї категорії.

## Amazon Cognito

**Призначення:** Керування автентифікацією користувачів і федерацією
identity providers для застосунків.

### Ключові терміни

| Термін                      | Визначення                                                                                                                |
|-----------------------------|---------------------------------------------------------------------------------------------------------------------------|
| **User Pool**               | Cognito каталог користувачів для sign-up/sign-in і видачі JWT.                                                            |
| **Identity Pool**           | Cognito компонент, що видає тимчасові AWS credentials через IAM roles.                                                    |
| **App Client**              | У контексті Amazon Cognito це поняття описує відповідний елемент сервісу, його налаштування або поведінку під час роботи. |
| **Hosted UI**               | У контексті Amazon Cognito це поняття описує відповідний елемент сервісу, його налаштування або поведінку під час роботи. |
| **User Attributes**         | У контексті Amazon Cognito це поняття описує відповідний елемент сервісу, його налаштування або поведінку під час роботи. |
| **Groups**                  | У контексті Amazon Cognito це поняття описує відповідний елемент сервісу, його налаштування або поведінку під час роботи. |
| **Federation**              | У контексті Amazon Cognito це поняття описує відповідний елемент сервісу, його налаштування або поведінку під час роботи. |
| **OIDC/SAML**               | У контексті Amazon Cognito це поняття описує відповідний елемент сервісу, його налаштування або поведінку під час роботи. |
| **JWT**                     | Підписаний JSON Web Token із claims про identity або permissions.                                                         |
| **ID/Access/Refresh Token** | У контексті Amazon Cognito це поняття описує відповідний елемент сервісу, його налаштування або поведінку під час роботи. |
| **MFA**                     | У контексті Amazon Cognito це поняття описує відповідний елемент сервісу, його налаштування або поведінку під час роботи. |
| **Lambda Triggers**         | У контексті Amazon Cognito це поняття описує відповідний елемент сервісу, його налаштування або поведінку під час роботи. |
| **Role Mapping**            | У контексті Amazon Cognito це поняття описує відповідний елемент сервісу, його налаштування або поведінку під час роботи. |

**Типовий екзаменаційний сценарій:** Потрібні sign-up/sign-in та JWT →
User Pool; потрібні тимчасові AWS credentials користувачеві → Identity
Pool.

**Екзаменаційна пастка:** User Pool автентифікує; Identity Pool видає
AWS credentials. Це різні функції.

| **Identity-based**         | У контексті AWS IAM це поняття описує відповідний елемент сервісу, його налаштування або поведінку під час роботи. |

| **Managed/Inline Policy**  | У контексті AWS IAM це поняття описує відповідний елемент сервісу, його налаштування або поведінку під час роботи. |

| **Access Key**             | У контексті AWS IAM це поняття описує відповідний елемент сервісу, його налаштування або поведінку під час роботи. |

**Типовий екзаменаційний сценарій:** Lambda/EC2 має викликати AWS API →
надати execution/instance role із мінімальними permissions.

**Екзаменаційна пастка:** Explicit Deny перекриває Allow. Не вбудовуйте

| Термін                    | Визначення                                                                                                         |

| **Key Material**          | У контексті AWS KMS це поняття описує відповідний елемент сервісу, його налаштування або поведінку під час роботи. |

| **Customer Managed Key**  | У контексті AWS KMS це поняття описує відповідний елемент сервісу, його налаштування або поведінку під час роботи. |
| **Key Policy**            | Основна resource policy, що визначає доступ до KMS key.                                                            |
| **Grant**                 | У контексті AWS KMS це поняття описує відповідний елемент сервісу, його налаштування або поведінку під час роботи. |

| **Alias**                 | Іменований покажчик на конкретну версію Lambda.                                                                    |
| **ARN**                   | У контексті AWS KMS це поняття описує відповідний елемент сервісу, його налаштування або поведінку під час роботи. |

| **Encryption Context**    | Не секретні authenticated metadata, які мають збігатися під час decrypt.                                           |

**Типовий екзаменаційний сценарій:** Потрібне кероване шифрування даних
із контролем ключів → KMS.

**Екзаменаційна пастка:** Перевіряйте Key Policy разом з IAM policy; KMS
